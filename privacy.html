Privacy policy

Last updated 9 October 2026

Who uses Minion

Minion is a personal assistant used by one person, its owner. It isn't offered to the public, and there are no other users.

What Minion accesses

With the owner's permission, granted through Google sign-in, Minion can read the owner's Gmail messages and create drafts in the owner's own Gmail accounts. It sends an email only after the owner has heard a summary of that draft (recipients, subject and attachments) and approved it. Minion never deletes, labels or changes the owner's existing mail.

How the data is used

Email content is used only to help the owner: to summarise and prioritise new mail, to find messages and contacts, and to write drafts the owner asks for. To do this, relevant message text is processed by the AI services Minion uses (Google Gemini and Anthropic Claude) under those providers' API terms. It isn't used for advertising, sold, or shared with anyone else.

Where the data is stored

Access tokens and any notes Minion keeps are stored only on the owner's own devices. Minion doesn't run a server that stores other people's data.

Google API data

Minion's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can remove Minion's access at any time at myaccount.google.com/permissions.

Contact

Questions about this policy can be raised with the owner through the GitHub profile that hosts this page.
